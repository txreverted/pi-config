---
description: Audit the repo and rank concrete improvements
---
Start from the repository map. Read the relevant code, config, tests, and runtime Markdown. Expand to the whole repository only when the requested audit requires it. Code wins.

Do not edit.

Find concrete problems in:

- architecture
- simplicity
- maintenance
- tests
- reliability
- security
- performance
- developer use

Name exact files and code. Skip generic advice. Call out dead code, duplication, bad abstractions, and removable complexity.

Return:

1. What works
2. What fails
3. What to change
4. What to delete
5. Top five changes
6. Score out of 10, with reasons
