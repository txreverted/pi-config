---
Analyze the whole repo in depth. Understand the system before judging it.

Code is source of truth. Do not trust docs blindly.

Review:

* architecture
* code quality
* simplicity
* maintainability
* tests
* reliability
* security
* performance
* DX

Find:

* what is good
* what is bad
* dead / duplicate code
* bad abstractions
* useless complexity
* things to remove
* things to merge
* things to simplify
* things to rethink

Be critical. No generic advice. Point to exact files / code.

Rate the codebase `/10` and explain why.

Finish with:

1. What is good
2. What is bad
3. What should change
4. What should be removed
5. Top 5 highest-impact improvements

Do not change code yet.
